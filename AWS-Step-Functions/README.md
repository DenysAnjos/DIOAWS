# AWS Step Functions
Este projeto teve como objetivo consolidar meus conhecimentos em workflows automatizados utilizando AWS Step Functions.
A proposta do laboratório foi criar um repositório organizado contendo anotações e insights adquiridos durante a prática, servindo como material de apoio para estudos e futuras implementações.

O que é o AWS Step Functions?
O AWS Step Functions é um serviço utilizado para criar fluxos de trabalho automatizados. Ele permite organizar etapas de uma aplicação, conectando serviços e definindo a ordem em que cada ação deve acontecer.

* Entender o funcionamento básico do AWS Step Functions

2. Acesso ao serviço AWS Step Functions

## Insights adquiridos
* Entendi que o AWS Step Functions é usado para criar e organizar workflows automatizados
* Aprendi que uma máquina de estados representa as etapas de um processo
* Percebi que o Step Functions ajuda a coordenar diferentes serviços AWS
* Entendi que workflows podem ter etapas sequenciais, paralelas e condicionais
* Aprendi que o serviço é útil para orquestrar processos mais complexos
* Percebi que o uso de workflows facilita a visualização e o controle de processos automatizados
* Entendi que o GitHub pode ser utilizado para registrar anotações técnicas e acompanhar a evolução dos estudos
