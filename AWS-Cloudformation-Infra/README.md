# Infraestrutura Automatizada com AWS CloudFormation

## Objetivo

Este laboratório teve como objetivo implementar uma infraestrutura automatizada utilizando AWS CloudFormation, aplicando conceitos de Infrastructure as Code (IaC).

## Recursos criados
- Amazon EC2
- AWS CloudFormation

## Processo realizado
1. Criação do template YAML
2. Upload do template para o CloudFormation
3. Criação da Stack
4. Provisionamento automático da instância EC2
5. Validação dos recursos criados

## Insights adquiridos
- Entendi como o CloudFormation automatiza o provisionamento de recursos
- Aprendi a criar uma instância EC2 utilizando Infrastructure as Code
- O uso de templates facilita a padronização de ambientes
- Alterações na infraestrutura podem ser versionadas através do código
- CloudFormation reduz atividades manuais e aumenta a consistência dos deployments
