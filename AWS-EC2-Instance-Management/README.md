# Gerenciamento de Instâncias EC2 na AWS

Este projeto teve como objetivo consolidar meus conhecimentos em gerenciamento de instâncias EC2 na AWS, aplicando conceitos vistos no curso em um ambiente prático.

A proposta do laboratório foi criar um repositório organizado contendo anotações, etapas realizadas e insights adquiridos durante a prática, servindo como material de apoio para estudos e futuras implementações.

O que é uma instância EC2?
Uma instância EC2 é um servidor virtual na AWS. Com ela, é possível executar aplicações, sistemas, testes e serviços em nuvem sem a necessidade de manter um servidor físico próprio.

Durante o gerenciamento de uma instância EC2, é possível configurar pontos como:
* Tipo da instância
* Sistema operacional
* Armazenamento
* Regras de segurança
* Par de chaves
* Estado da instância
* Região de execução

## Metas
* Aplicar conceitos aprendidos no curso
* Entender o funcionamento básico de uma instância EC2
* Criar e gerenciar uma instância na AWS
* Compreender a importância dos Security Groups
* Documentar o processo realizado
* Utilizar o GitHub como ferramenta de documentação técnica

## Recursos utilizados:
* Amazon EC2
* AWS Management Console
* Security Group
* Key Pair
* GitHub
* Visual Studio Code

## Processo realizado
1. Acesso ao console da AWS
2. Navegação até o serviço Amazon EC2
3. Criação de uma nova instância EC2
4. Escolha da imagem do sistema operacional
5. Seleção do tipo de instância
6. Configuração do par de chaves
7. Configuração do Security Group
8. Revisão das configurações da instância
9. Inicialização da instância
10. Verificação do estado da instância
11. Análise das informações principais, como IP público, região e status
12. Encerramento da instância após a prática para evitar custos

## Insights adquiridos
* Entendi melhor como uma instância EC2 funciona na prática
* Aprendi que o tipo da instância influencia diretamente nos recursos disponíveis
* Entendi a importância dos Security Groups para controlar o acesso à instância
* Aprendi que uma instância em execução pode gerar custos se não for encerrada
* Percebi a importância de revisar região, tipo de instância e armazenamento antes da criação
* Entendi que documentar o processo facilita consultas futuras e reforça o aprendizado
* Aprendi que o GitHub pode ser usado como portfólio e material de apoio técnico
